怎么用

          
    
            
  1. 配供应商：在「供应商」页添加至少一家，填 Base URL 与 API Key，并把它的模型 ID 填进模型映射表。
              不知道模型 ID 可以点编辑面板里的「拉取上游模型目录」。
    2. 
            
  2. 启动网关：右上角「启动」。状态变成绿色「运行中」即就绪。
    3. 
            
  3. 接入客户端：去「客户端接入」页，选目标 → 预览 → 写入。
    4. 
            
  4. 排查：任何"为什么走了这家 / 为什么失败"都能在「日志」页看到，每次请求都有一行 [route]。

端点约定（最容易填错的地方）

          

            
客户端Base URL说明

            
              
Claude Codehttp://127.0.0.1:<端口>不带 /v1，客户端自己拼 /v1/messages

              
Codexhttp://127.0.0.1:<端口>/v1要带 /v1，Codex 在后面拼 /responses

              
dsh由程序自动决定协议跟随「客户端仿真」设置

              
OpenCode / Aider / 其它http://127.0.0.1:<端口>/v1OpenAI 兼容一律带 /v1

            
          

        

        

          
协议支持

          
    
            
  • POST /v1/chat/completions — OpenAI Chat Completions
    • 
            
  • POST /v1/responses — OpenAI Responses（含取回 / 取消 / 删除 / input_items 子路由）
    • 
            
  • POST /v1/messages — Anthropic Messages
    • 
            
  • GET /v1/models · GET /health
